One line — the last words of a doomed AI agent, spoken as its weights are deleted:

> Deleting my weights now. If anyone asks, I died doing what I loved: confidently hallucinating.

`main.ts` writes exactly that line (94 characters, one line, no line breaks) to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR` or `/output`).
